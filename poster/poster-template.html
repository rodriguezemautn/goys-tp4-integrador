Problema y Objetivos del Proyecto

El Problema: En operaciones de TI tradicionales, el NOC (monitoreo de métricas y rendimiento) y el SOC (detección de intrusiones) operan como áreas desconectadas. Ante un ciberataque, la respuesta manual de un analista puede demorar minutos u horas, degradando la disponibilidad del servicio.

Solución Implementada: Diseñamos un laboratorio contenerizado donde Suricata IDS inspecciona el tráfico de red en tiempo real sobre el bridge virtual. Ante una alerta, un agente en Python clasifica el evento con asistencia de un LLM (Groq API) o heurística local y aplica reglas DROP inmediatas en el kernel Linux (iptables FORWARD), neutralizando el ataque de forma automatizada sin degradar el acceso a los clientes legítimos.

Stack Tecnológico e Integración

  • SOC / Detección: Suricata 8.0 en modo IDS sniffer sobre la interfaz virtual br-monitored con telemetría en eve.json.
  • Módulo de Respuesta: Script en Python 3.11 con Groq SDK (modelo 27B) que realiza análisis contextual del payload con salida JSON estructurada.
  • Remediación Perimetral: Inyección dinámica de directivas DROP en la cadena FORWARD de iptables.
  • NOC / Observabilidad: Servidor Prometheus y Grafana con aprovisionamiento automático de dashboards y telemetría en tiempo real.
  • Alta Resiliencia: Modo de contingencia heurística local offline en caso de cortes de internet durante la feria.

Comprobación del Filtrado en Tiempo Real:

  • Atacante (172.28.0.99): Las peticiones posteriores son descartadas de inmediato a nivel de kernel (Timeout / Drop total).
  • Clientes Válidos: El portal institucional web (Nginx) responde continuamente con código HTTP 200 OK sin degradación.
  • Consola NOC: Grafana incrementa el contador de amenazas neutralizadas y traza el evento en la línea de tiempo.
